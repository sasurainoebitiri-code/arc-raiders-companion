# ARC Raiders 総合攻略ツール（ファンメイド）

マップイベント・クエスト・アイテム図鑑・必要素材・ハイドアウト・設計図・スキルツリー・トレーダー・プロジェクト・ARC図鑑・武器比較・マップを1つにまとめた非公式ツールです。進捗はブラウザ内に保存されます。

## データの出典
- アイテム・ハイドアウト・トレーダー・プロジェクト・ARC・スキル・地図: [RaidTheory/arcraiders-data](https://github.com/RaidTheory/arcraiders-data)（MIT License）/ [arctracker.io](https://arctracker.io)
- マップの場所データ（物資・ARC・脱出地点など）: [MetaForge](https://metaforge.app/arc-raiders)（API利用条件に基づき出典表示）
- クエストの画像・攻略メモ・マップイベントの予定: [ARC Raiders Wiki](https://arcraiders.wiki/)（CC BY-SA）
- クエスト手順の画像: [神ゲー攻略](https://kamigame.jp/arcraiders/)（掲載許可を得て、各画像に出典とリンクを表示）
